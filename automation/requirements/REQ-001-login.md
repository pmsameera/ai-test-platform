Requirement ID: REQ-001

Title: User Login

Description:
A registered user must be able to log into the application using
valid credentials.

Acceptance Criteria:

1. A user can log in using valid credentials.

2. An invalid username or password displays an appropriate error.

3. Username is required.

4. Password is required.

5. Password must not be displayed as plain text.

6. After successful authentication, the user is redirected to
   the products page.
